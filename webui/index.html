实时请求

每次上游尝试为一行（无展开），按时间倒序；Request ID 截断显示、可搜索，行内可复制完整 Request ID；客户端会话标识仅参与搜索、不单独成列。密钥区分匿名与认证密钥，不设通道列。缓存命中与输入/输出仅在该尝试为请求最终尝试且上游已报告用量时显示，其余显示“—”（HTTP 400/429 等未报告 Token 的尝试永不显示估算）。缓存未命中可由总输入减缓存命中推导（包含缓存写入与普通未缓存提示词，非精确拆分），故不设独立列。无尝试投影的请求以回退请求行补齐，不丢失。

全局就绪

路由可用性：全局凭证可用性 + 指派池传输健康；单模型目标冷却不计入。完整密钥与代理密钥永不展示。

代理健康

节点名始终为代理节点名，不代表出口 IP。代理池为具名代理池标识；路由引用列显示该池被匿名 / Zen / Go 的引用归属；路由凭证为路由到该池的配置级凭证数（同池各行相同），不是绑定。健康仅表示传输连通性。探测为单行健康操作，只改变传输健康，不触碰凭证 / 目标调度状态；繁忙时返回 HTTP 409。
