代理限流冷却（429 全局）

按通道与池限定的 429 冷却：同一池内同 URL 按通道隔离，Zen 匿名与认证共享 Zen 通道，Go 独立。限流期间该通道暂不使用该代理。
通道名代理池节点活跃失败次数剩余下次可用失败分类状态

通道可用性冷却（403/5xx 比较探测）

按通道与池限定的 403/5xx 通道冷却：仅比较探测写入（同凭证一节点成功而另一节点 403/5xx），无比较成功时仅展示不写入；与传输、限流、凭证冷却及按模型目标冷却相互独立。
通道名代理池节点活跃失败次数剩余下次可用失败分类状态

活跃目标冷却（403/5xx 按模型）

仅含 403/5xx 触发的按（凭证×池×代理×模型）目标冷却，最多显示 512 条；429 见代理限流冷却，通道级 403/5xx 见通道可用性冷却。

系统配置

按任务分组查看与修改运行配置。保存时自动校验，失败保留原配置；监听地址与管理开关需重启生效。顶部提示栏会显示需重启的已保存项。

接入与鉴权

决定请求优先走哪个上游，以及匿名试用与各类密钥是否可用。

代理池与路由

具名代理池是稳定的池标识，被匿名 / Zen / Go 选中的池为运行中，其余为暂存：不运行、不可探测、不计容量。条目为代理节点，支持 direct、HTTP(S)、SOCKS5(H)；节点名不代表出口 IP。

备用模型渠道

当匿名渠道在已有对话中暂时不可用时，可由已启用的备用渠道继续处理。渠道名称唯一，基础地址仅支持 HTTP/HTTPS，需填写模型与 API 密钥；启用选择经保存后生效。

上游服务与重试

上游服务地址与单密钥重试预算、请求超时。修改后立即生效。
